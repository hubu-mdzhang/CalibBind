# E-SWAP · 波长反事实交换套件（359 题）

从 579 题全集构造的受控反事实评测：成对交换候选波长区间，并以交换后的波长在候选集内
重新推导参考答案。用于检验模型输出是否跟随物理证据（而非标签字符串或位置先验）。

## 数据

- `eswap_ds.json` — 359 道题（579 初筛 → 剔除 220：其中 138 题因交换伙伴不在候选集内
  新真值不可选，其余为新真值不可定义）。sha256 见下。

## 构造与审计

- `scripts/build_eswap_dataset.py` — 构造脚本（初筛、交换伙伴配对、真值重推导）。
- `scripts/audit_eswap_v2.py` — 构造审计：候选可行性 / 索引映射 / 唯一命中三类断言，
  587 元素零失败通过后冻结。
- `scripts/eswap_judge.py` — 评测判分（含 selftest）。
- `scripts/eswap_build_report.py` — 构建报告。

## 结果口径（论文 §4.2）

含波长档 86.0% 输出跟随新真值（926/1077）；阴性对照 1.8%（低于随机 p95 = 12.8%）；
序号类任务 84.2% 与名字类 90.9% 一致。注意：v1 套件（`eswap_ds_v1_invalid`，未随本仓库
发布）存在构造缺陷（新真值不可选 138/138），已作废，勿与 v2 混用。
